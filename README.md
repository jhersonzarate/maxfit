## Mejoras e Implementaciones Pendientes

Se deben mejorar los modals de cada vista para que tengan un diseño más moderno, ordenado y profesional, además de optimizar la experiencia visual y funcional del usuario.

Revisar y corregir las validaciones del sistema, ya que actualmente algunos mensajes aparecen duplicados. Se debe optimizar la lógica de validación tanto en frontend como en backend para evitar errores repetitivos y mejorar la interacción con el usuario.

Implementar correctamente la gestión de roles dentro del sistema, así como las secciones de Tipo de Documento, Cargos y Tipo de Clase en el menú de administración, asegurando que todo funcione de manera dinámica y correctamente relacionado con la base de datos.

Mejorar el módulo de métodos de pago. El sistema debe permitir registrar nuevos métodos de pago y cada uno debe contar con su respectivo estado para controlar su disponibilidad dentro del sistema.

Verificar la generación de IDs en todas las entidades del proyecto. Revisar el código para confirmar si ya existe una lógica de enumeración o autogeneración de IDs implementada y, en caso contrario, desarrollarla correctamente para mantener consistencia y evitar conflictos en la base de datos.

También se recomienda revisar y optimizar el código general del proyecto, manteniendo buenas prácticas de desarrollo, organización y estructura tanto en Java Web JSP como en la base de datos.
